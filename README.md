# Luis Castellanos — Portfolio

This is my personal portfolio built with Next.js, TypeScript, and Tailwind CSS.  
It showcases my software engineering projects, experience, and technical growth as a CSE Student.

The site features an interactive terminal-style navigation system alongside traditional navigation, combining creativity with usability. It includes dedicated project pages, a floating command widget, and structured sections for experience and contact. 

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel Deployment

## Features
- Terminal-driven route navigation
- Dedicated project detail pages
- Resume preview route
- Responsive design
- Clean, minimal UI with structured layouts

Built to reflect both my technical skills and my approach to building thoughtful user experiences.
